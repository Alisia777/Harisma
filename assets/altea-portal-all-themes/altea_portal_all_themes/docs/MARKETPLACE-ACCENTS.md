# MARKETPLACE MICRO-ACCENTS

Цвет площадки — только навигационная подпись. Максимальное визуальное покрытие одного цвета: 8% viewport.

Разрешено: dot 6–8 px, линия 2 px, chip, одна серия графика, активный фильтр, левая кромка строки.

Запрещено: цветной фон всей страницы, цветные таблицы-шахматки, несколько насыщенных градиентов в одной карточке.

- **Wildberries** — `#A855F7` (`wb`)
- **Ozon** — `#4F86FF` (`ozon`)
- **Яндекс Маркет** — `#F2C84B` (`ym`)
- **Золотое Яблоко** — `#72C86A` (`goldapple`)
- **Л’Этуаль** — `#D96AA9` (`letu`)
- **Магнит Маркет** — `#E85B55` (`magnit`)
