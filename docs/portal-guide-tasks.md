# Как вести задачник

Задачник собирает ручные задачи, авто-сигналы и задачи по запуску новинок.

Базовый порядок:

- новая задача должна иметь owner, срок, тип и площадку;
- статус меняется по факту движения: новая, в работе, ожидание, сделано;
- комментарии фиксируют решение или причину задержки;
- авто-задачи можно дополнять, но не нужно дублировать вручную.

Если задача относится к конкретной сети, укажите площадку, чтобы фильтры РОП и сети показывали ее корректно.
