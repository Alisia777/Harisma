# Рыночный слой репрайсера v4

## Приоритет решения

1. Статус товара и наличие на площадке.
2. OOS-защита и актуальность прямого остатка.
3. Полная экономика: себестоимость, комиссия ИУ, издержки площадки, внутренняя реклама и налог.
4. MIN/MAX маржа SKU.
5. Ручной MIN/MAX цены.
6. Оборачиваемость и прогноз спроса.
7. Сезонность, собственная эластичность, цены того же SKU на других площадках и конкуренты.
8. Согласование РОП и cooldown после изменения цены.

Рыночный слой не может пробить маржинальный floor, опустить цену при OOS-риске или обойти согласование РОП.

## Сигналы

- **Сезонность.** Используется дневная история спроса. Для рабочего индекса нужно не менее 56 дней, для высокой уверенности — 330 дней. Индекс ограничен диапазоном 0,8–1,2. Ожидаемый сезонный пик блокирует снижение цены.
- **Эластичность.** Обучается только на собственной истории SKU: минимум 42 наблюдения, три реальные смены цены, три уровня цены и достаточный `R²`. Положительная или слабая модель отклоняется; тогда используется консервативный пороговый коэффициент.
- **Другие площадки.** Сравнивается клиентская цена того же артикула. Из-за различий СПП, комиссии и логистики сигнал не задаёт цену напрямую и может изменить существующий шаг не более чем на 1 п.п.
- **Конкуренты.** Требуются свежие клиентские цены минимум трёх сопоставимых предложений. Используется медиана, а не минимальная цена. Просроченные, OOS, валютные, несопоставимые упаковки и слабые match-score исключаются.

Суммарное дополнительное влияние рынка ограничено тремя процентными пунктами. Любое изменение остаётся в режиме ожидания РОП.

## Загрузка конкурентов

Создать шаблон:

```bash
node scripts/import-repricer-competitor-prices.js template \
  --output output/repricer-competitor-template.xlsx
```

Проверить и принять заполненный файл:

```bash
node scripts/import-repricer-competitor-prices.js import \
  --input /путь/к/competitors.xlsx \
  --data-dir data
```

Импорт атомарный: если хотя бы одна строка содержит критичную ошибку, рабочий snapshot не меняется. Попытка и ошибки сохраняются в `repricer_competitor_import_history.json`.

## Аудит в портале и Excel

В карточке площадки отображаются сезонный индекс, источник эластичности, медиана конкурентов и разрыв между площадками. В полном Excel-аудите дополнительно доступны количество наблюдений, `R²`, свежесть, число доверенных предложений и фактическое влияние рынка на шаг цены.
